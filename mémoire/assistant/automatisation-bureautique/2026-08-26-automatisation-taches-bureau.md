# 2026-08-26 — Automatisation tâches bureau

## Objectif
Permettre à l'agent "assistant de bureau" d'exécuter des tâches bureau (doc,
mail, calendrier) via le skill `officecli` et l'horodateur `cron`.

## Composants
- `officecli` (skill) — opérations bureautiques.
- `cron` (skill) — tâches planifiées.

## Interprétation
Sandbox obligatoire pour toute exécution de code côté bureau.
