# Session du 2026-09-03 — test du workflow du coffre

Première note de session (`VAULT-CONTRACT.md` §9). Objectif : parcourir le
coffre comme le ferait un utilisateur ordinaire, sur deux demandes — une sans
skill, une avec — pour voir où le workflow tient et où il frotte.

## Décisions prises

- Le rendu SVG de Mermaid est confirmé **hors coffre uniquement**. Dans une
  note, le bloc Mermaid brut reste la forme retenue.
- Les prérequis d'un skill doivent être vérifiés **à l'exécution**, pas à
  l'installation : `mermaid-cli` répondait à `-h` tout en étant incapable de
  produire un fichier.

## Points soulevés et tranchés

1. **`brouillon/README.md` contredisait le contrat.** Il affirmait que
   `brouillon/` était « le seul endroit du coffre où un agent peut écrire
   directement », alors que le §2 en autorise trois : `brouillon/`,
   `mémoire/<nom-agent>/` et `IA/skills/` sous condition. Il annonçait en
   prime un patch Git pour déplacer un contenu vers `mémoire/`, qui n'en
   demande pas. Corrigé dans la même session : le README renvoie désormais au
   contrat au lieu de le reformuler.
2. **`verifier_coffre.py` ne regarde pas `brouillon/`.** Cohérent avec le
   caractère jetable de la zone, mais rien ne le disait. Consigné dans le
   README de `brouillon/`.
