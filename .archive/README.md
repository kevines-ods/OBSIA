# .archive/ — ce qui a été retiré du coffre

Le §2 du contrat interdit toute suppression sans archivage préalable. Ce
dossier reçoit ce qui a quitté le coffre actif.

Il est **versionné** : ignoré par Git, un archivage ne survivrait pas à un
clone neuf, et la règle du §2 ne promettrait rien.

Rien ici n'est vivant :

- aucun fichier de ce dossier n'est lu par un agent ;
- rien n'y est indexé — ni sommaire, ni index, ni balayage des noms de notes,
  les dossiers commençant par un point étant écartés partout ;
- le contenu y est conservé **tel qu'il était**, y compris ses erreurs.

## Contenu

### `mémoire/assistant/stack-tauri/` et `mémoire/assistant/interface-panneaux/`

Retirés le 2026-09-04. Ces deux notes décrivaient le cadre applicatif et la
disposition d'une interface graphique. OBSIA ne nomme aucune interface et ne
s'attache à aucun programme : le coffre décrit *quoi* faire, le harness
fournit *avec quoi*. Ces notes attachaient le coffre à un choix d'outillage
extérieur, ce qui n'est plus admis.

Elles sont conservées ici parce qu'elles retracent une étape réelle du projet,
pas parce qu'elles font encore autorité. Elles ne font plus autorité du tout.
